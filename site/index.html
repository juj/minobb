minobb

Minimum-volume oriented bounding boxes of 3D point sets, in C++.

The code and its documentation are in the GitHub repository. These pages go with it:

  • Test results: the computation times of the convex hull and of the bounding box for several thousand models of the Objaverse data set, as charts and as a table.
  • The contact categories A–D: example polyhedra for each of the ways in which a minimum box touches the edges of a polyhedron.
  • The proof that a minimum-volume box has three edge contacts, which is what makes the algorithm exact.
  • The Lean proof, step by step: the machine-checked version of that proof, explained for readers who do not know Lean.
  • The paper (Jylänki 2015) that introduced the algorithm.
